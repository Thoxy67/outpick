Inputs: a modern source picker for LG webOS

A native overlay that replaces LG's input menu on rooted webOS TVs (tested on webOS 6 and webOS 25).

  • HDMI inputs named after the device plugged in (HDMI-CEC), with live previews of the source being watched and the last picture of the others.
  • CEC options per input (power, device home, menu, info), USB storage and DLNA media servers, and a Home entry that follows Luma or Glasshouse Home.
  • Row, grid, list or docked sidebar layouts, nine positions, eight themes and accent colours, French and English.
  • Optional takeover of the remote's Source key (and the Multikey button on remotes without one), reversible from the app's own settings.

Requires root (Homebrew Channel). Open it once from the app list, then use Customize.
